Mapping iOnly these values change. Each corner is checked on its own, so 0 and anything not listed stay as they are. A corner can be bound to a radius token at the new value, or written as a number. Writing a number on a bound corner removes its variable.
Inclusions iOnly change a frame, layer, or component whose name matches one of these exactly. Nested layers, variants, and instances of a match are included. Leave this empty to update every layer in scope. Matching is case-insensitive.
Exclusions iSkip a component when its name contains one of these, including variants and instances. Button also skips Icon Button. Matching is case-insensitive.
